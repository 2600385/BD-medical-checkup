# BD-medical-checkup
검진센터 브로셔

## 일만사·웰체크 제안 키트 (`bd-proposal-tool.html`)

검진센터에 일만사·웰체크를 제안할 때 쓰는 브로셔 3종을 담은 HTML 툴입니다.
브라우저에서 파일을 열면 상단에서 병원명을 입력할 수 있고, 입력한 병원명이 세 브로셔 전체에 바로 반영됩니다.

- **유형 01 · 검진결과 연동형** — 인당 수가가 가장 높은 유형. 수가 항목별 예상 금액을 직접 입력·수정하며 합계를 확인할 수 있습니다.
- **유형 02 · 검진결과 혜택형** — 고위험군 발굴 → 일만사 등록 → 포인트 지급 → 재방문으로 이어지는 Lock-in 흐름을 강조합니다.
- **유형 03 · 혜택형 + 비대면관리형** — 웰체크 비대면관리 화면(예시, 실제 캡처로 교체 필요)과 함께 "병원과 환자와의 끈을 이어줍니다"를 핵심 메시지로 제안합니다.

세 유형 모두 케어플랜 시 건강기능식품 제공, 검체검사 위수탁제도 개편(수가 발생 유형), 포인트·정기 교육자료 발송·비대면관리라는 공통 메시지를 담고 있습니다.
