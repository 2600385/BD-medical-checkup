# BD-medical-checkup
검진센터 브로셔

## 검진센터 제안 BD 툴 (`index.html`)

검진센터에 일만사·웰체크를 제안할 때 쓰는 실제 브로셔 3종(`assets/posters/`)을 보여주는 HTML 툴입니다.
브라우저에서 파일을 열면 상단에서 병원명을 입력할 수 있고, 각 브로셔 좌측 상단에 병원명+유형 배지가 바로 얹힙니다.

- **유형 01 · 검진 결과 연동형** (`assets/posters/type1-linked.png`)
- **유형 02 · 혜택형** (`assets/posters/type2-benefit.png`)
- **유형 03 · 혜택+비대면관리형** (`assets/posters/type3-benefit-remote.png`)

각 브로셔 하단에는 공통 "체크 포인트" 섹션(국가검진 vs 일만사검사 비교, 위협·기회·Lock-in·차별화 4가지 이유)이 붙어 있고, 병원명 입력창 옆 출력 버튼으로 원하는 유형만 골라 인쇄할 수 있습니다.
